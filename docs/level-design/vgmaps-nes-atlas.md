# VGMaps NES atlas

Index page: https://vgmaps.com/Atlas/NES/index.htm
(Section list: https://vgmaps.com/Atlas/index.htm#NES)

The NES atlas is very large: the index page is about 750,000 characters and lists roughly 850
games with thousands of map images, mostly credited to individual mappers. Nearly all are "ripped".
Rights belong to the map creators and game publishers; check https://vgmaps.com/Copyright.htm before
reusing any image. No images are copied into this repo.

This catalog is a curated shortlist, not the full list. It keeps the games whose level structure
translates to Intellivision-sized screens (single-screen arcade, maze, and puzzle-platform designs).
Numbers in brackets are how many map entries the atlas shows for that game, as read from the page
text on 2026-11-26. The text was read in chunks by a summarizing tool, so a count may be off by a
few. Look up any game on the index page by title.
